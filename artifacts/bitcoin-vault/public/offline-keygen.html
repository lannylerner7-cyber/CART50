Your vault. Your access key.

This tool generates 64 cryptographically random bytes, encoded as 86 base64url characters. This is an access credential, not an AES encryption key or a Bitcoin seed.

Replacing an exposed key: install this new verifier in Coolify and deploy the updated application. The updated app rejects old 164-byte keys and clears legacy sessions and passkeys on first access. Generating this file alone does not revoke anything on your server.

Use this file offline

  1. Save this HTML file to your computer and disconnect from the internet.
  2. Open the saved file locally. Generation is blocked on web-hosted copies.
  3. Generate your key and save the keyfile manually in secure offline storage.
  4. Install only the SHA-256 verifier in VAULT_OWNER_VERIFIER through your server's secrets manager. Never paste the key into chat.

Save before closing

No recovery email or password reset exists. Losing all access keys and passkeys can lock you out of the dashboard.

The key stays in this page's memory only. Closing the page discards it. Your verifier is not a login credential. Keep Bitcoin seeds and backup encryption keys separate.
