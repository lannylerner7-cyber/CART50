Offline Signet setup

Creates a new signer token and a disposable public test-wallet descriptor. Does not change your owner login key or configure Coolify.

Test coins only. This is not a hardware wallet or a production cold wallet. Never send real BTC. Generation works only from a downloaded local HTML file, not this page's web preview.

1. Find your website's network

In the server terminal, run docker network ls --format '{{.Name}}'. Inspect your website container's networks to identify the shared network; do not guess:

docker inspect --format '{{json .NetworkSettings.Networks}}' YOUR_WEBSITE_CONTAINER

2. Save the private recovery backup

This download contains an unencrypted private test-wallet descriptor. Keep it offline; never paste it into Coolify, GitHub or chat. Losing it means losing access to test coins received by this wallet. Each click of Generate creates a different wallet and token—do not regenerate an existing deployment's values.

3. Enter the four variables in Coolify

Use HTTPS or a secure SSH tunnel. Store the token as a runtime secret, not a build argument. Use the same signer token in the website later. Do not share screenshots containing these values.

Generating values does not deploy the services or verify recovery. Save the backup, then verify the receiving address and recovery before using this test wallet.
